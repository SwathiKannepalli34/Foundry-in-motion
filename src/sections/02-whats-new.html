What's new, and how ready each feature is

Foundry changes monthly. This section was re-checked against Microsoft Learn on November 11, 2026: recent additions from the "What's new" page and the feature readiness table from the general availability overview. Use it to decide what is safe to put in production and what to pilot.

Rule of thumb for customers. Preview features are provided without a service-level agreement and Microsoft does not recommend them for production workloads. Decide your policy up front, and use the documented controls to hide or block preview features in production environments.

Recent additions worth knowing

AutopilotsAgents with their own Entra agent user account (mailbox, calendar, Teams presence), built from hosted-agent blueprints, so they can work with a whole team. {{doc:agents/concepts/autopilot-overview|Overview}}
Long-running hosted agents PreviewCrash recovery, stream replay with reconnect, steering an in-flight turn, human-in-the-loop approval and a durable state store. {{doc:agents/concepts/long-running-agent-resilience|Resilience}}
Routines GARun a prompt or hosted agent on a timer, a schedule or an event such as a GitHub issue or a Teams channel message. {{doc:agents/concepts/routines|Routines}}
Bring your own registryHosted agents can pull from an authenticated non-Azure registry using OIDC token exchange; private ACR is supported for projects created after June 25, 2026. {{doc:agents/how-to/private-registry-connections|Guide}}
Toolbox GATool search, skills and a private skill catalog are preview add-ons. New guidance on network isolation for toolboxes. {{doc:agents/how-to/tools/toolbox-network-isolation|Network isolation}}
Foundry IQAPI-level GA with preview portal access; a knowledge base can feed a Microsoft Copilot Studio agent Preview. {{doc:agents/concepts/what-is-foundry-iq|Foundry IQ}}
ObservabilityMicrosoft Entra authentication for trace ingestion Preview, plus Agent 365 data collection and permissions. {{doc:observability/how-to/trace-ingestion-entra-authentication|Entra ingestion}}
EvaluationsSDK guides for conversations, datasets, deployed interactions and synthetic data, and cloud evaluations with admin-connected models. {{doc:observability/how-to/cloud-evaluation|Cloud evaluation}}
ModelsGPT-6.1 and GPT-6 families, Claude Fable 5.2 and Mythos previews, MAI-Thinking-1 and Grok guides, Fireworks on Foundry, and a six-phase model migration guide. {{doc:foundry-models/concepts/model-migration|Migration guide}}
Developer toolsFoundry Toolkit for VS Code, Foundry Canvas (a GitHub Copilot App extension), and the Foundry MCP Server Preview. {{doc:how-to/develop/get-started-projects-visual-studio-code|Toolkit}}
Responsible AIContent provenance (C2PA and text watermarking), customer-managed key guidance, and data privacy and abuse monitoring (next sections). {{doc:responsible-ai/content-safety/provenance-disclosure|Provenance}}
Foundry Control Plane PreviewFleet inventory, compliance, quota and the AI Gateway in one place, with Agent 365 for identity-based governance. {{doc:control-plane/overview|Control plane}}

Every modelEach model has a retirement date; retirement without a replacement returns HTTP 410 Gone after notice.Track the lifecycle policy and plan migrations early.

Authentication

Foundry supports API key authentication for most areas, with exceptions: evaluations, the dataset tab, Content Understanding, agents and workflows require Microsoft Entra ID. For governance-sensitive workloads use Entra ID with RBAC; keys do not give the same role-based granularity.

Rollout pitfalls from the docs

  • Treating preview features as production dependencies without approval.
  • Skipping region and model availability checks.
  • Assuming every GA feature works behind a virtual network (traces and workflow agents do not yet fully support network isolation).
  • Building new production dependencies on workflows.
